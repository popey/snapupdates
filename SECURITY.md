# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Snap Store Updates, please report it responsibly.

**Do not open a public issue.** Instead, please email **alan@popey.com** with:

- A description of the vulnerability
- Steps to reproduce
- The potential impact

I will acknowledge your report within 48 hours and aim to provide a fix or mitigation as quickly as possible.

## Scope

This policy covers the Snap Store Updates application at [snapupdates.popey.com](https://snapupdates.popey.com) and the source code in this repository.

Out of scope:
- The Snap Store API itself (managed by Canonical)
- Cloudflare infrastructure

## Supported Versions

Only the latest deployed version is supported. There are no versioned releases.
